# zet

A ray traced renderer in Rust. This workspace has been constructed as a learning project.

- `docs/learning-path.md`: the plan to learn the necessary concepts.
- `docs/architecture-draft.md`: the architecture the project is heading toward.
- `crates/`: measurements tooling + quick shader preview.

```
cargo run -p lab                   # quick shader preview; F1 toggles the overlay, F12 captures, Esc quits
cargo test --workspace             # tooling tests 
```

See `docs/learning-path.md` for the full command list and other details.
